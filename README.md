# SpendWise - Expense Tracker

A console-based expense tracker written in Python.

## Features
- Add, view, and delete expenses
- Category summary with totals
- Data saved automatically to a JSON file
- Input validation for amounts and dates

## How to run
1. Install Python 3.10 or newer
2. Clone this repository
3. Run: `python main.py`

## What I learned
Functions, dictionaries, file handling with JSON, input validation, and error handling.
